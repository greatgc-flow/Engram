Usage:
  engram <command> [options]
  engram help <command>            same as: engram <command> --help

Daily use:
  engram open        Open a workspace (the default when no command is given)
  engram update      Check for and apply runtime, tool and Python updates
  engram doctor      Report environment health (read-only, no network)
  engram menu        Manage the Explorer right-click "Open in Engram" entry
  engram version     Print the Engram version

Health & repair:
  engram isolation   Check optional Sandbox and WSL2 providers (read-only)
  engram repair      Detect and fix a broken Python/venv, launchers or manifest
  engram relocate    Re-anchor the install after the folder was moved/renamed
  engram tidy        Clean temp files, caches and old environment backups

Backups & state:
  engram backup      Back up personal AI data (.engram/) to a zip archive
  engram restore     Restore personal AI data from a backup archive
  engram snapshots   List, pin and restore environment backups (Python, venv)

Removal:
  engram reset       Delete personal AI data (a safety snapshot is taken first)
  engram uninstall   Remove Engram's program files (your data is kept)

Run 'engram <command> --help' (or 'engram help <command>') for the full
options, examples and exit codes of one command.

Safety model (shared flags and execution rules):
  --apply      execute a new plan; tidy, repair, relocate, restore, reset and
               'snapshots restore' preview by default. Repair, relocate and
               reset still ask unless --yes. Ordinary tidy, restore and
               snapshots restore do not ask; tidy --purge-legacy asks unless
               --yes.
  --dry-run    preview only; always wins over --apply. Cannot be combined
               with repair/relocate --resume or --rollback (exit 2).
  --yes, -y    skip ordinary confirmation prompts. Uninstall --purge-data
               still requires the typed folder name.
  --json       machine-readable output (doctor, isolation check, repair,
               relocate and snapshots list).
  Recovery (--resume/--rollback) executes directly.
  Update core/tools and uninstall execute after a prompt (--yes skips it).
  Update --dry-run/--check and uninstall --dry-run preview only. Managed
  environment updates and update --latest preview until --yes.
  Menu disable/clean remove entries immediately. Replaced Python/venv copies
  move into a backup registry, never deleted outright.

Common workflows:
  First time in a new folder:       engram
  Keep everything up to date:       engram update --yes
  Update only the AI CLIs:          engram update --only claude,codex,agy --yes
  Update only the embedded Python:  engram update --only python --yes
  Something feels broken:           engram doctor ; engram repair --apply
  Folder moved or renamed:          engram relocate --apply
  See or protect env backups:       engram snapshots list | pin NAME
  Reclaim disk space:               engram tidy --apply
  Remove leftover *_old folders:    engram tidy --adopt-legacy --apply
  ...and delete them right away:    engram tidy --purge-legacy --apply
  Back up / restore your AI data:   engram backup ; engram restore PATH --apply
  Start over, keep the programs:    engram reset --apply
  Remove Engram:                    engram uninstall --dry-run, then uninstall

Exit codes (common): 0 ok, 1 failed (including "Engram is not set up" when
initialization is required), 2 usage error (unknown command or option),
3 declined at a prompt (repair and relocate: 10), 10-14 environment
operations (see 'engram repair --help'). Command help adds verb-specific
meanings.
