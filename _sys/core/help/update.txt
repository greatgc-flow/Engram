engram update - check for and apply updates

Usage: engram update [--yes] [--check | --dry-run] [--refresh] [--only NAMES]
       engram update --only python|venv|packages [options]
       engram update -o python|nodejs --latest [-y] [options]

Description:
  Bare update, --check and --dry-run show what is outdated and exact next
  commands. Core and tools apply here after confirmation (or with -y).
  Python, venv and packages need their own -o invocation, without tool names.
  Anything that cannot be checked is listed under "Not checked" and is never
  counted as up to date. Unlike tidy/repair, update is plan + prompt rather
  than dry-run + --apply: --yes is what skips the prompt.
  python, venv and packages are managed environment components: they run
  through the journaled repair engine (a backup is taken before the swap,
  dry-run by default, --yes applies) and cannot be mixed with tool names.
  --latest requires --only python or --only nodejs and defaults to a dry-run
  plan; add --yes to apply. It cannot be combined with --to.

  Python defaults to the latest patch in the installed minor. Offline or failed
  discovery falls back to the pin; default updates never downgrade or cross
  a minor. --latest selects the highest stable Python, including minor jumps,
  and never downgrades. Failed/offline discovery reports latest unavailable
  and fails without falling back to the pin. Major jumps still need
  --allow-major-runtime-upgrade. Every minor jump checks the embed zip and
  managed pip resolution of the complete baseline before any swap.
  Without a pinned SHA-256, a warning and the computed hash are printed;
  the hash is recorded in the journal and still gates cached archive reuse.
  Python shows installed, latest patch (same minor) and latest minor only
  when newer versions exist; otherwise it says up to date or could not check.
  Minor update advice requires verified archive and dependency readiness.
  Blocked or unverifiable targets show warnings without executable advice.
  Next steps lists verified minor and applicable patch/core/tool commands.
  Package advice requires evidence that packages are outdated.
  Example --check output (versions are illustrative):
    Python:
      Installed: 3.13.7
      Latest patch (same minor): 3.13.9
      Latest minor: 3.14 (3.14.8)
      Patch update: engram update -o python -y
    Python 3.14 dependency readiness verified.
      Next: engram update -o python --latest -y
    Next steps:
      engram update     Apply core + tools after confirmation
      engram update -y  Apply core + tools without prompting
      engram update -o python -y
      engram update -o python --latest -y

Venv:
  A PATCH swap keeps env/venv and its packages and refreshes the interpreter
  link. A MINOR swap rebuilds env/venv using virtualenv (embedded Python has
  no stdlib venv), reinstalls the baseline for the new interpreter, restores
  requested packages at their recorded versions, and reinstalls editable
  installs whose path still exists. Missing paths are skipped and reported.
  Failures before commit roll back both Python and venv trees.

Options:
  --yes, -y        Apply without asking (default: plan for Python or --latest;
                   otherwise ask first)
  --check          Print the plan only; exit 1 for failed or unchecked
                   requested components (default: off; for scripts and CI)
  --dry-run        Discover and show the plan, apply nothing (default: off)
  --refresh, -r    Ignore the discovery cache and re-check online (default:
                   use the cache)
  --only, -o LIST  Update only these components, comma- or space-separated;
                   aliases cc, cx, ag work (default: everything)
  --allow-major-runtime-upgrade
                   Let a base runtime cross a major version, e.g. Node.js
                   22 to 24 (default: off; major jumps are shown, not applied)
  --to X.Y.Z       With --only python: explicit target (default: latest
                   patch in the installed minor)
  --latest         With --only python or nodejs: discover the latest version;
                   Python uses the highest stable release, Node its existing
                   channel and major guard. No pin fallback (default: off)
  --all-packages   With -o packages only: upgrade baseline plus requested
                   non-editable extras (default: baseline only). Does not
                   affect Python swaps.
  --force          With --only python: reinstall even when already current;
                   override missing minor pre-flight checks (default: off)
  --offline        With --only python: use only local files (default: off)
  -h, --help, /?   Show this help (default: off)

Examples:
  engram update
  engram update --yes
  engram update --check
  engram update --only claude,codex,agy --yes
  engram update --only python --yes
  engram update --only python --to 3.14.8 --yes
  engram update -o python --latest -y
  engram update -o nodejs --latest
  engram update --only nodejs --allow-major-runtime-upgrade --yes

Exit codes:
  0   success or nothing to do; --check completed all requested checks
  1   a component failed, or --check found something unchecked
  2   usage error (unknown option or component)
  3   declined at the prompt
  10-14  managed environment codes; 11 is preflight refusal before mutation

See also:
  engram doctor    what is installed and healthy
  engram snapshots   the backups an update leaves behind
  engram tidy      remove old backups once you are happy

Confirmed updates maintain layout, merge declarations, retire obsolete shipped
files, and clean preserved update staging. Preview and --check skip this
maintenance.
