## Operator commands

Run from a development checkout. Point the catalog command at a disposable ordinary directory. PowerShell users can pass the three descriptor filenames explicitly.

```sh
python -B tools/feasibility/pack_catalog.py /path/to/synthetic-system _sys/tests/fixtures/optional-pack/*.descriptor.json
python -B tools/feasibility/pack_environments.py _sys/tests/fixtures/optional-pack/*.descriptor.json
python -B -m pytest -q _sys/tests/unit/test_optional_pack_catalog.py _sys/tests/unit/test_pack_environment_probe.py _sys/tests/unit/test_check_unreferenced_functions.py
```

The second command creates three temporary venvs with pip disabled. It loads each interpreter twice using isolated mode and an exact executable path. Each environment imports its own Python module, reports its base prefix, and checks its private workspace sentinel. The fixture roots are discarded after the run. Production package deployment, lockfile compatibility for real consumers, an installed-state reader and a public pack CLI require their separate gates.

## Registry observation and install preview

The catalog command accepts an explicit `--installation-id` when inspecting a synthetic system root. The v1 fixture registry is read-only. Each entry must resolve to a catalog slot and profile. An owned `DATA_RETAINED` result requires matching installation, package and slot identities plus the expected SHA-256 of `<slot>/state/ownership.json`. Installed claims remain `PARTIAL` until artifact, environment and launch readiness can be resolved independently. The inspector emits `FOREIGN` for a different installation or receipt identity and `CORRUPT` for a torn registry or malformed receipt. An unregistered directory remains `UNKNOWN`. The original catalog-only output remains available by omitting the expected identity. The receipt format is scoped to this feasibility probe.

The pure `optional_pack_plan.install_preview` uses the same code for all three fixture descriptors. It builds a single staging action for an absent slot and binds the revisions, root fingerprint, exact manifest SHA-256, selected generation, space requirement and interval. The SHA-256 input is the ASCII label `EPP-PREVIEW-1`, a NUL byte, and sorted-key compact JSON of the plan body without its digest. `check_preview` rebuilds using fresh fixture observations and an explicit UTC clock. Sufficient free space is rechecked. Neither function executes actions. These fixtures do not authenticate a production registry, publisher, approval or runtime binding.

The registry's four RED tests failed before the CLI accepted the expected owner. The install preview's three RED tests failed at the missing module. All seven pass. Network-isolated Linux regression also ran the catalog, real environment, wiring and Python registry suites together: 163 passed, 19 subtests passed. Windows CI on draft PR #147 records the final native result.
