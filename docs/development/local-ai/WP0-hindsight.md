# WP0 Hindsight Windows dependency feasibility

This T75 / POC-03 fixture qualifies an exact dependency closure separately from service startup. It uses Hindsight API slim 1.3.0 and Engram's reviewed full portable CPython 3.14.10 x64 archive. It does not introduce the Hindsight API metapackage, an embedded PostgreSQL provider or any AI model.

The resolution used uv 0.13.9 against PyPI, target `x86_64-pc-windows-msvc`, with wheel-only selection. Both 3.13.18 and 3.14.10 produced the same 186 package versions and published hash sets. Only the 3.14 candidate was downloaded and narrowed to one exact Windows-compatible wheel per distribution. The retained lock is reviewed for the probe. It is an input to native validation and is not an approved product lock. The Hindsight wheel SHA-256 is `82232942f3819e5f9b685aa10be18358d1eb2b885457f703d768842b0d792448`.

The 186 selected compressed files total 394,808,232 bytes before the interpreter or any model. The `claude-agent-sdk` wheel alone is 178,194,377 bytes. The base slim package declares Claude and GitHub Copilot SDKs and pulls ONNX Runtime through document tooling. Engram's existing CLI remains the interactive entrypoint. Those packages are vendor dependencies in the isolated fixture and are never launched by the probe. Omitting a required dependency would break the declared closure. A product packaging decision still needs measured installed space, a security/license review and comparison with a supported slimmer upstream option.

The native workflow checks hash-only offline reconstruction, `pip check`, the Hindsight help entrypoint and installed distribution version, and CPython-native asyncpg, psycopg2, tokenizer and NumPy imports. The subprocess receives a temporary home and an allowlist of environment variables. The import/entrypoint smoke rejects observed Python socket and process-launch events, which supplies a fixture assertion for that execution path. The first workflow reached the import stage after offline install and `pip check`. Its network probe initially treated a local hostname read as egress. After narrowing that assertion, all four compiled imports reached the entrypoint. Hindsight 1.3.0 rejected `--version` with usage exit 2. The corrected fixture checks the version through installed package metadata and invokes the supported `--help` command with explicit local placeholder configuration. The network/process assertion still applies. Final native execution is pending.

The wheel defaults select an embedded database (`pg0`), a hosted LLM provider, and local default models with additional dependencies. A native service pilot must provide the separately proven PostgreSQL DSN and explicitly qualify every generation, embedding, reranking and Knowledge Bank provider, including side-specific overrides. Hindsight service startup, local inference, Memory and Knowledge Bank API round-trips and production egress enforcement remain separate gates.
