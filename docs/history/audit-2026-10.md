## 3. Lessons learned

| Lesson | Durable consequence |
| --- | --- |
| Peers cannot run full pytest in their sandbox | Maintainer executes full suite after each wave; static review never substitutes for execution. |
| Hosted dry-run catches what local cannot | New root files must pass root hygiene (6e89471); validate packaged installation. |
| WinGet 0x8A150046 | Source agreements must be accepted on uninstall too (88044c9). |
| Upgrade gate version precondition | Candidate version must satisfy the updater's upgrade rule (88044c9). |
| cp1252 stdout without Engram environment | Harness must use product UTF-8 environment; English messages avoid incidental encoding failure (a438973). |
| Scheduled job on nonexistent self-hosted runner | Queued run blocks its concurrency group; cancel obsolete queued runs and keep runner optional. |
| Chain commit with && | Commit only if preceding checks succeed; record failures before retry (3e326b7). |
| Hosted execution is not Windows Sandbox or ACP=949 proof | Preserve explicit provider and locale evidence boundaries. |
