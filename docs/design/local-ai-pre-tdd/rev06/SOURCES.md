## 5. Follow-up coverage and explicit design changes

- Every **supported, authorized** AI activity and accessible prior history, not literal indiscriminate surveillance. Source enrollment/coverage, Git/CI and data provenance added (Spec 7,9; Contracts 3–4).
- PeerHub inputs/outputs/outcomes: verified current read paths, optional lightweight export with independent cursor channels, source-owned feedback and no Hindsight dependency (Spec 8; Contracts 5; T92–T99,T149).
- Memory taxonomy: episodic, semantic, procedural, evaluative, personal, prospective, sensory/source, working, relational and meta; banks by scope/trust, not one DB per type; KB added as separate source-oriented service within Hindsight (Spec 9–11).
- Context: actual effective allocation, model and cache, role budgets, native agent compaction, no fake context; prior rough VRAM illustration replaced by architecture-specific formula + real profile gate (Spec 6).
- Hippocampal and sleep analogies: associative retrieval and bounded evidence replay, one shared idle coordinator; OpenClaw native Dreaming not global writer, Hindsight automatic consolidation controlled; no actual neural simulation or autonomous model-weight training (Spec 11,13).
- All previous lifecycle/portability/CLI/multi-Python/SecondBrain exclusions retained. New commands proposed but not implemented, native plugin features conditional. Design risk decisions are disclosed in DECISIONS.md. Actual source enrollment and thresholds require owner review. No repository code or test execution in this package.
